# Changelog

## 2.0.1 — 2026-10-12

- Fixed My Voices showing every accessible voice, including unsaved defaults. Membership now comes from the paginated `voice_type=saved` API query. Saved library voices and defaults explicitly added to a collection remain in My Voices.
- Added My Voices, ElevenLabs Voices, and All voices filters to the shared TTS, Voice Changer, and batch selector. Changing source selects a visible voice or clears the selection when the list is empty.
- Added a separate available-voices view alongside shared-library discovery. Voice lists refresh on launch; cached membership remains separate from edit/delete ownership permissions.
- Added API and application regression tests for source separation, pagination, old caches, search, and empty lists.

## 2.0 — 2026-10-12

### Added

- Separate workspaces for text generation, Voice Changer, sound effects, transcription, audio isolation, dubbing, voices, the audio library, and batch jobs.
- Account model discovery, model language metadata, and speech-language controls independent of interface language.
- A shared voice library alongside account voices, existing voice previews, search, voice design, instant cloning, and ownership-gated metadata editing and deletion.
- Microphone recording for Voice Changer, local audio playback with seeking, and explicit audio export.
- Single-file, multiple-file, and folder import for TXT, SRT, and VTT; subtitle text is extracted without preserving cue timing.
- ElevenLabs generation history retrieval and a local index of downloaded recordings.
- English and Polish localization with an interface-language preference that can change during a session.
- The supplied application icon, with macOS icon sizes generated by the build tooling.
- Mock API contract tests, import/media tests, localization checks, and developer documentation.

### Changed

- Renamed the application from Folder → Głos to Voice Desk.
- Replaced the folder-first interface with a native workspace sidebar and a prominent text editor.
- Moved API key storage, connection validation, and account usage information into Settings.
- Separated Voice Changer from text generation. New words in an existing or cloned voice use Text to Speech; conversion uses a source recording.
- Added output destination selection for batches while retaining MP3, M4A, WAV, source basenames, explicit start, cancellation, and resume caching.
- Kept interface text separate from speech language and avoided translating user input.

### Reliability

- Restricted authenticated requests to the official API host and prevented credentials from following redirects to another host.
- Added scoped authentication, quota, subscription, input, and response errors without exposing the API key.
- Required API ownership confirmation before voice edit or delete operations; voice categories do not establish ownership.
- Added validation for supported imports, file sizes, source changes, symbolic links, subtitle content, and audio duration.
- Preserved completed downloads on failure and retained explicit retries instead of automatically repeating billable requests.

### Compatibility

- Requires macOS 14 or later on Apple Silicon.
- Retains the earlier Keychain service identity and compatible default-generation cache identities.
- The application remains an ElevenLabs API client. Account permissions and plan restrictions still determine which operations are available.
- [TESTING.md](TESTING.md) records the verification scope; mock results are not live-service validation.
