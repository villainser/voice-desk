# ElevenLabs API integration

Voice Desk sends AI operations exclusively to the official ElevenLabs API. The client uses Foundation `URLSession`; it does not install speech models or call another audio-generation provider. This reference describes the routes implemented in [APIService.swift](Sources/APIService.swift) and the response types in [APIModels.swift](Sources/APIModels.swift). The contracts below were checked against official documentation on 2026-10-11.

## Authentication and account access

API requests use `https://api.elevenlabs.io` with the `xi-api-key` header. The app stores the key in macOS Keychain. Authenticated requests reject redirects to other hosts. Voice-preview URLs and signed dubbing-output URLs are fetched without the API-key header.

A valid key does not necessarily grant access to every feature. Keys may have restricted scopes, and workspace permissions, voice availability, subscription limits, and remaining allowance still apply. HTTP 401, 403, 402, 422, and 429 receive distinct application messages. Server error details are truncated and the active key is redacted. Requests are never automatically retried, including billable requests.

`GET /v1/user/subscription` provides the displayed subscription tier, period usage, allowance, voice slots, and cloning entitlement when returned. The remaining allowance is the reported `character_limit` minus `character_count`, clamped at zero. It is not an estimate of generation cost or a guarantee that another endpoint is permitted. [Subscription reference](https://elevenlabs.io/docs/api-reference/user/subscription/get)

## Voice list membership

The client fetches all available voices and the paginated `GET /v2/voices?voice_type=saved` list. My Voices uses saved membership, not the unfiltered available list or a category-based ownership guess. ElevenLabs Voices shows the remaining available voices; shared-library discovery is a separate tab. A default explicitly saved to a collection belongs in My Voices, as does a saved community voice. Editing and deletion still require `is_owner=true`. Old caches without membership are refreshed on launch; a failed saved lookup does not classify the entire catalog as external. [List voices contract](https://elevenlabs.io/docs/api-reference/voices/search), checked 2026-10-12.

## Text and language behavior

The selected voice and model are independent of the interface language. Model languages are populated from `GET /v1/models`; a cached response supports offline selection but does not establish current account access. The original Unicode text is preserved, including mixed-language text. The app does not translate it.

Auto-detect omits `language_code`. For explicit language selection, the app uses the selected model's advertised languages. The TTS client independently omits `language_code` for Multilingual v2 because the endpoint does not support that parameter for this model. Selected expressive delivery tags, when enabled, are an explicit generation setting rather than a translation step. [TTS contract](https://elevenlabs.io/docs/api-reference/text-to-speech/convert)

Voice language labels and verified-language metadata describe the voice, but do not prove exclusivity to those languages. Pronunciation and accent can vary. A cloned or designed voice can be selected for normal Text to Speech without recording a new performance for each script.

## Voice Changer behavior

The endpoint accepts a source recording and a target `voice_id`. It aims to preserve performance details such as delivery, emotional cues, whispers, and accent while changing the voice. It does not accept a replacement script or a translation target. The app separates importing or recording audio, choosing a target voice, conversion, playback, and export. [Voice Changer overview](https://elevenlabs.io/docs/overview/capabilities/voice-changer)

The current service limit is 300 seconds per source segment across subscription tiers. `eleven_multilingual_sts_v2` supports multilingual conversion; `eleven_english_sts_v2` supports English. The model selector also respects live `can_do_voice_conversion` flags. The app does not split long recordings automatically. [Duration limit](https://elevenlabs.io/docs/help-center/product/core-capabilities/voice-changer/what-is-the-max-input-length-when-using-voice-changer)

The documented encoded audio inputs include MP3, M4A, FLAC, OGA, OGG, and WAV; the native client exposes formats it can validate locally. Speech-to-speech supports a streaming endpoint, but Voice Desk currently downloads the complete result before playback. Playing an existing voice preview uses its `preview_url` and does not trigger a fresh paid generation. [Input formats](https://elevenlabs.io/docs/help-center/product/core-capabilities/voice-changer/which-formats-can-be-used-as-the-input-audio-for-voice-changer), [streaming endpoint](https://elevenlabs.io/docs/api-reference/speech-to-speech/stream)

## Dubbing lifecycle

Dubbing is a translation workflow separate from Voice Changer and multilingual TTS. The client uses the current project API rather than the legacy dubbing endpoint. Creating a project with `target_language` queues its first target; the initial charge includes that target. Source preparation progresses through queued/preparing/ready or failed; the language target separately progresses through queued/processing/completed or failed. The interface refreshes status when requested rather than polling continuously. [Project creation](https://elevenlabs.io/docs/api-reference/dubbing/create-project)

Completed targets expose `outputs.lossless_audio`, a signed FLAC download URL valid for about one hour. Refresh the target to obtain a new URL after expiry. Dubbing v2 language codes and regional dialects must match the published supported list. Provider warnings about replacement voices are retained in the typed response. [Language target](https://elevenlabs.io/docs/api-reference/dubbing/language-targets/get-language-target), [supported dubbing languages](https://elevenlabs.io/docs/help-center/product/dubbing/which-languages-are-supported-in-dubbing)

## Audio formats and client limits

TTS, Voice Changer, Voice Design previews, and Sound Effects request `mp3_44100_128`. M4A and WAV export are local standard-codec operations; converting MP3 to WAV does not restore information removed by MP3 compression. The client does not request high-bitrate or high-rate API formats without accounting for plan restrictions. The official contract reserves MP3 192 kbps for Creator or higher and PCM 44.1 kHz for Pro or higher. [Output-format reference](https://elevenlabs.io/docs/api-reference/text-to-speech/convert)

The API upload helper limits each operation to 100 MiB, including the combined samples of an instant clone. This is an app memory limit, not a claim about the maximum accepted by every ElevenLabs endpoint. Files must be nonempty regular files; symlink uploads are rejected. Returned isolation/history containers are detected from bytes and checked by the native audio layer before playback or export.

## Verification and boundaries

[APITests.swift](Tests/APITests.swift) covers request contracts, optional metadata, pagination, ownership, language omission, multipart uploads, preview decoding, dubbing lifecycle responses, credential-free downloads, validation failures, and secret redaction. [CoreTests.swift](Tests/CoreTests.swift) covers generation batching, downloaded-chunk reuse, output handling, and Voice Changer requests. Tests use synthetic data and mocked HTTP responses, never the user's key.

Read-only live calls to models, account voices, and subscription succeeded in the shipping app on 2026-10-12; an existing voice preview also downloaded and entered native playback. Live generation, feature-specific subscription entitlements, cloning verification, and real voice quality still require separate testing with an authorized account. Passing contract tests does not establish those results. See [TESTING.md](TESTING.md) for executed checks and remaining manual validation.

Professional Voice Cloning training/identity verification, real-time STT, speech streaming playback, voice remixing, music, conversational agents, enterprise transcript overrides, and dubbing transcript editing are not exposed by this release. Their absence does not imply that ElevenLabs lacks those APIs. A native permission or subscription error is shown when an implemented operation is unavailable to the current account.
